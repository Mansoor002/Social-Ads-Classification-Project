##  Social Media Ads Classification Project

##  Project Overview
This project is a **Machine Learning Classification** model built to predict whether a user will purchase a product after viewing a social media ad, based on their **Age** and **Estimated Salary**.

* **Problem Type:** Binary Classification (`Purchased: 0 or 1`)
* **Algorithm Used:** Supervised Machine Learning Models

---

##  Dataset Details (`Social_Network_Ads.csv`)
The dataset contains the following features:
* **User ID:** Unique ID for each user.
* **Gender:** Gender of the user (Male/Female).
* **Age:** Age of the user.
* **Estimated Salary:** Annual/monthly salary of the user.
* **Purchased:** Target variable (`0` meaning did not purchase, `1` meaning purchased).

---

##  Key Steps & Workflow
1. **Data Preprocessing:** Checked for missing values and formatted data.
2. **Exploratory Data Analysis (EDA):** Analyzed how Age and Estimated Salary impact purchasing behavior.
3. **Feature Scaling:** Standardized the features for optimal model performance.
4. **Model Training & Evaluation:** Trained the model and evaluated accuracy using confusion matrices and classification reports.
